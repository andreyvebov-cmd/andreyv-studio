# Andrey V Studio — видеоредактор

Одностраничный веб-сайт для дизайнера Andrey V. Загрузка видео, применение модных эффектов с настройкой каждого параметра в реальном времени, экспорт результата в MP4.

## Особенности

- Интерактивная панель эффектов с переключением и настройкой параметров
- Реальное время применения эффектов через Canvas2D
- Набор эффектов:
  - Chroma Key (зеленый экран)
  - Glitch
  - Film Grain с виньеткой и тонировкой
  - RGB Split
  - Wave искажение
  - Пикселизация
  - Неоновое свечение
  - Retro (сканлайны, хроматическая аберрация, изгиб)
  - Направленное размытие
- Настраиваемые параметры для каждого эффекта (цвета, интенсивность, скорость и т.д.)
- Сохранение состояния активных эффектов
- Обновление UI при изменении эффектов
- Экспорт обработанного видео в MP4 с использованием ffmpeg.wasm

## Установка

Поскольку проект представляет собой одностраничное веб-приложение, достаточно разместить файлы `effects.js` и `index.html` на веб-сервере или открыть локально в браузере.

## Использование

1. Откройте `index.html` в браузере.
2. Используйте панель эффектов для включения/выключения эффектов и настройки их параметров.
3. Эффекты применяются к видео в реальном времени через Canvas2D.
4. Нажмите кнопку "💾 Экспорт MP4" для сохранения обработанного видео.

## Технические детали

- Эффекты реализованы как методы объекта `Effects`, который манипулирует данными изображения через `CanvasRenderingContext2D`.
- Параметры эффектов хранятся в `Effects.params` и обновляются через ползунки и цветовые выборки.
- Активные эффекты отслеживаются в массиве `Effects.active`.
- Функция `updateUI()` перестраивает панель параметров при изменении активных эффектов.
- Экспорт реализован через захват холста с помощью `canvas.captureStream()`, запись в WebM через `MediaRecorder`, затем конвертация в MP4 с использованием ffmpeg.wasm (либри x264).
